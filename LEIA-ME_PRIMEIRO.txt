IMPORTANTE: LEIA ISTO ANTES DE ABRIR O PROJETO!

1. COMO ABRIR O PROJETO NO ANDROID STUDIO
   ----------------------------------------
   
   a) Feche o Android Studio se estiver aberto
   
   b) Abra o Android Studio
   
   c) Na tela inicial, clique em "Open"
   
   d) Navegue até a pasta "WalkDog_DB" 
      (a pasta que contém este ficheiro)
   
   e) Selecione esta pasta e clique "OK"
   
   f) Aguarde a sincronização do Gradle completar


2. SE TIVER ERRO DE CACHE DO GRADLE
   ---------------------------------
   
   a) Feche o Android Studio
   
   b) Execute o ficheiro: limpar_gradle_cache.bat
   
   c) Aguarde a conclusão
   
   d) Reabra o Android Studio


3. SE TIVER ERRO DE CARACTERES NO CAMINHO
   ---------------------------------------
   
   Erro: "path contains non-ASCII characters"
   
   a) Feche o Android Studio
   
   b) Execute: mover_projeto.bat
   
   c) Aguarde copiar para C:\Projetos\WalkDog_DB
   
   d) Abra o novo caminho no Android Studio

6. VERIFICAÇÃO RÁPIDA
   -------------------
